## Install Script

The recommended way to install is using the install script:

```sh
curl -sSf https://irc.example.com/install.sh | sh
```

The script will:
1. Detect your OS and architecture
2. Download the latest release from GitHub
3. Install binaries to `/usr/local/bin` (or `$IRC_INSTALL_DIR`)

You can customize the install directory:

```sh
IRC_INSTALL_DIR=~/.local/bin curl -sSf https://irc.example.com/install.sh | sh
```

## Download Binaries

Pre-built binaries are available on the [GitHub releases page](https://github.com/example/irc/releases).

| Platform | Server | CLI | GUI |
|---|---|---|---|
| Linux x86_64 | `irc-server-linux-x86_64` | `irc-linux-x86_64` | `irc-gui-linux-x86_64` |
| Linux aarch64 | `irc-server-linux-aarch64` | `irc-linux-aarch64` | `irc-gui-linux-aarch64` |
| macOS x86_64 | `irc-server-darwin-x86_64` | `irc-darwin-x86_64` | `irc-gui-darwin-x86_64` |
| macOS aarch64 | `irc-server-darwin-aarch64` | `irc-darwin-aarch64` | `irc-gui-darwin-aarch64` |
| Windows x86_64 | `irc-server-windows-x86_64.exe` | `irc-windows-x86_64.exe` | `irc-gui-windows-x86_64.exe` |

Download, make executable, and move to your PATH:

```sh
chmod +x irc-server-linux-x86_64
sudo mv irc-server-linux-x86_64 /usr/local/bin/irc-server
```

## Build from Source

You'll need [Rust](https://www.rust-lang.org/tools/install) (1.85+).

```sh
git clone https://github.com/example/irc.git
cd irc
cargo build --release
```

Binaries are placed in `target/release/`:

```sh
ls target/release/irc-server target/release/irc target/release/irc-gui
```

## Verify Installation

```sh
irc-server --version
irc --version
```
