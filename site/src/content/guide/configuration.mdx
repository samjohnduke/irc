## Configuration File

The server reads configuration from a TOML file passed with `--config`. All sections are optional — sensible defaults are used when omitted.

## Server Section

```toml
[server]
name = "irc.example.com"   # Server hostname shown in messages
bind = "0.0.0.0"           # Address to bind to
port = 6667                # Port to listen on (6697 for TLS)
motd = "Welcome to the server!"
```

## TLS Section

```toml
[tls]
cert = "/path/to/cert.pem"  # TLS certificate chain
key = "/path/to/key.pem"    # TLS private key
```

When `[tls]` is present, the server requires TLS for all connections.

## Limits Section

```toml
[limits]
max_clients = 1000       # Maximum concurrent connections
max_channels = 500       # Maximum channels
max_nick_length = 30     # Maximum nickname length
max_topic_length = 390   # Maximum topic length
max_message_length = 512 # Maximum message length (including CRLF)
```

## Operator Section

Define server operators who can use commands like `KILL`, `REHASH`, and `DIE`:

```toml
[operator]
name = "admin"
password = "a-strong-password"
```

Operators authenticate with the `OPER` command:

```
OPER admin a-strong-password
```

## Environment Variables

Some settings can also be configured via environment variables:

| Variable | Description | Default |
|---|---|---|
| `IRC_BIND` | Bind address | `0.0.0.0` |
| `IRC_PORT` | Listen port | `6667` |
| `IRC_LOG` | Log level (`trace`, `debug`, `info`, `warn`, `error`) | `info` |

## Logging

The server uses `tracing` for structured logging. Control the log level with the `IRC_LOG` environment variable or `RUST_LOG`:

```sh
IRC_LOG=debug irc-server --config server.toml
```
