## Overview

The irc project is a modern IRC suite built in Rust. It includes three components:

- **irc-server** — a full-featured IRC server with TLS, channel modes, and operator tools
- **irc** — a terminal IRC client
- **irc-gui** — a graphical IRC client

All components are distributed as single static binaries with no runtime dependencies.

## Quick Start

The fastest way to get started is with the install script:

```sh
curl -sSf https://irc.example.com/install.sh | sh
```

This detects your platform, downloads the latest release, and installs all three binaries.

Or follow the [installation guide](/guide/installation/) for manual download and build-from-source instructions.
