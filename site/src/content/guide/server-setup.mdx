## Starting the Server

Start with defaults (listens on `0.0.0.0:6667`):

```sh
irc-server
```

Or with a configuration file:

```sh
irc-server --config server.toml
```

## Basic Configuration

Create a `server.toml` file:

```toml
[server]
name = "irc.example.com"
bind = "0.0.0.0"
port = 6697

[tls]
cert = "/path/to/cert.pem"
key = "/path/to/key.pem"

[limits]
max_clients = 1000
max_channels = 500
max_nick_length = 30

[operator]
name = "admin"
password = "change-me"
```

See [Configuration](/guide/configuration/) for the full reference.

## TLS Setup

For production, you should always enable TLS. You can use certificates from Let's Encrypt or any other CA:

```sh
# Generate a self-signed cert for testing
openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes
```

Then reference the files in your config:

```toml
[tls]
cert = "cert.pem"
key = "key.pem"
```

The server will listen on the configured port with TLS enabled.

## Running as a Service

### systemd

Create `/etc/systemd/system/irc-server.service`:

```ini
[Unit]
Description=IRC Server
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/irc-server --config /etc/irc/server.toml
Restart=on-failure
User=irc
Group=irc

[Install]
WantedBy=multi-user.target
```

Then enable and start:

```sh
sudo systemctl enable --now irc-server
```
