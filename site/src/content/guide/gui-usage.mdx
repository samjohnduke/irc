## Launching

Start the GUI client:

```sh
irc-gui
```

## Connection Dialog

On first launch, you'll be presented with a connection dialog. Enter:

- **Server** — the hostname (e.g., `irc.example.com`)
- **Port** — the port (e.g., `6697`)
- **TLS** — check this for encrypted connections
- **Nickname** — your desired nick

Click **Connect** to join the server.

## Interface Overview

The GUI is organized into panels:

- **Server list** (left) — connected servers and channels
- **Chat area** (center) — message history
- **User list** (right) — users in the current channel
- **Input bar** (bottom) — type messages and commands

## Using Commands

The GUI supports the same commands as the CLI client. Type them in the input bar:

```
/join #channel
/msg user Hello!
/nick newnick
```

## Features

- **Multiple servers** — connect to several servers simultaneously
- **Tab completion** — press Tab to complete nicks and channels
- **Notifications** — desktop notifications for mentions and private messages
- **Scrollback** — scroll through message history with the mouse or keyboard
- **URL detection** — clickable links in messages

## Configuration

The GUI stores its configuration at `~/.config/irc/gui.toml`. Server connections are saved automatically.
